# LUMI Config

Baseline experimental de provisionamento para Raspberry Pi 3 ARM64, Debian 13. Aplicação: https://github.com/fexdelux/lumi. Driver: https://github.com/fexdelux/LCD-show.

Execute `bash install.sh --dry-run` ou `bash doctor.sh`. Consulte [instalação](docs/installation.md), [arquitetura](docs/architecture.md) e [validação](docs/validation.md). Instalação limpa não homologada; não execute em produção sem backup. STT/TTS/wake word não incluídos. Meteorologia opcional, IA local. Não versionar credenciais nem calibração.

## Dynamic Audio
Compatibilidade de provisionamento com o código funcional LUMI v0.3.8, homologado no protótipo. Consulte [áudio](docs/audio.md). Instalação limpa ainda experimental; release da aplicação pendente.
